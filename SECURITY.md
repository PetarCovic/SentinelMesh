# Security policy

## Supported code

Security fixes are applied to the latest code on the `main` branch. Older
commits and forks do not receive separate maintenance.

## Reporting a vulnerability

Report suspected security vulnerabilities privately to Petar Covic through
[GitHub's vulnerability reporting form](https://github.com/PetarCovic/SentinelMesh/security/advisories/new).

Include:

- The affected component and commit or version.
- Steps to reproduce the issue using test data.
- The potential impact and any conditions needed to exploit it.
- Relevant logs or screenshots with credentials and personal information removed.

Use dummy credentials and synthetic images or recordings in reproduction
examples. Keep vulnerability details out of public issues and pull requests
while the report is being investigated.

The maintainer will review reports and coordinate fixes and public disclosure
with the reporter. This is a personal project, so response times depend on
maintainer availability.

Use [GitHub issues](https://github.com/PetarCovic/SentinelMesh/issues) for
ordinary bugs, documentation problems, and feature requests.
